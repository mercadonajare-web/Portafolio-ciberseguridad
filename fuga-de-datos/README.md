# Hoja de Trabajo: Fuga de Datos (NIST SP 800-53: AC-6)


Actividad práctica del **Certificado Profesional de Ciberseguridad de Google** enfocada en analizar un incidente de exposición de información interna y aplicar 
el principio de privilegio mínimo bajo el marco NIST.


## Análisis del Incidente


| Elemento | Respuesta |
| :--- | :--- |

| **Control** | Privilegio mínimo |

| **Problema(s)** | El hecho de no revocar los permisos para que la información solo fuera disponible para las personas correspondientes; se debió revocar todo antes de pasar al equipo de ventas |

| **Revisión** | El acceso o el mínimo privilegio: nadie debe tener permisos de sobra, que solo tengan acceso a lo mínimo indispensable para su trabajo o para poder realizarlo, y que se tengan roles y reglas claros para evitar este tipo de incidentes |

| **Recomendación(es)** | Asegurarse de tener una persona que se encargue de otorgar estos permisos de forma oportuna e indicada, que cada participante o trabajador de la actividad tenga controles más precisos, como auditorías continuas, para asegurar que los privilegios que se le otorgan sean solo los necesarios |

| **Justificación** | No quedarían huecos en los cuales una vulnerabilidad podría ser visible para cualquier tipo de atacante, asegurando zonas controladas y poco o nulos accesos no deseados |
