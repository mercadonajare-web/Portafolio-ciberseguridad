# Hoja de Trabajo: Fuga de Datos (NIST SP 800-53: AC-6)

Actividad práctica del **Certificado Profesional de Ciberseguridad de Google** enfocada en analizar un incidente de exposición de información interna y aplicar el principio de privilegio mínimo bajo el marco NIST.

## Análisis del Incidente

| Elemento | Respuesta |
| :--- | :--- |
| **Control** | Privilegio mínimo |
| **Problema(s)** | El hecho de no revovar los permisos para que la informacion solo fuera dispoinible para las peronas correspondientes se debio de revocar todo antes de pasar al equipo de ventas |
| **Revisión** | El acceso o el minimo privilegio que nadie debe de teer permisos de sobra, que solo tengan acceso a lo mimino indispensable para su trabajo o para poder realizarlo, y que se tengan roles y reglas claros para evitar este tipo de incidentes |
| **Recomendación(es)** | Asegurarse de tener una perosna que se encargue de otrogar estos permisos de forma oportuna y indicada que cada participoante o trabajor de activida dtenga controles mas precisos como autiorias continuas para asegurar que los privilegios que se le otrogan sean solo los necesarios |
| **Justificación** | No quedarian huecos en los cuales una vulnearbilidad podria ser visible para cualquier tipo de atavante asegurando zonas controladas y poco o nulos acceos no desaeados |
